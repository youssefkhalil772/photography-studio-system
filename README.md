## 🌟 المميزات الرئيسية

### 1. 🧾 نقطة البيع وإصدار فواتير جلسات التصوير (POS)
- واجهة كاشير سريعة وعصرية تدعم اختصارات لوحة المفاتيح والشاشات التي تعمل باللمس.
- إدارة خدمات التصوير (جلسات بورتريه، مناسبات، تصوير منتجات، تصوير أطفال)، حزم الخدمات، وطباعة الصور والألبومات.
- تحديد موظف المبيعات/الكاشير المسؤول، حساب الخصومات (مبلغ أو نسبة)، والدفعات المقدمة والمتبقي بدقة.
- طباعة إيصالات استلام حرارية (80mm / 58mm) تشمل شعار الاستوديو، تفاصيل الجلسة/الصور، ميعاد الاستلام المتوقع، QR Code، وحالة الحساب.
- متابعة دورة حياة الطلبات والتحميض: (`قيد التنفيذ` 📸 ⬅️ `جاهز للاستلام` 📦 ⬅️ `تم التسليم` ✅ ⬅️ `مرتجع` ❌).

### 2. 🖨️ إدارة الطابعات والباركود المباشر
- إمكانية ربط 3 طابعات مختلفة وتخصيصها من لوحة الإعدادات:
  - **طابعة الإيصالات الحرارية** (Thermal Receipt Printer).
  - **طابعة ملصقات الباركود** (Barcode Label Printer).
  - **طابعة التقارير والمستندات A4** (A4 Reports Printer).
- تخصيص أبعاد ملصق الباركود (عرض وارتفاع بالمليمتر) مع إمكانية إظهار اسم الاستوديو، اسم الخدمة، والسعر.
- **معاينة حية للملصق (Live Barcode Preview)** باستخدام مكتبة JsBarcode بدون الحاجة للاتصال بالإنترنت.
- زر لطباعة ملصق تجريبي والتأكد من توافق المقاسات والطابعة قبل التشغيل الفعلي.

### 3. 💬 تكامل الواتساب الذكي (Multi-Provider WhatsApp)
- دعم ثنائي متكامل: **WhatsApp Cloud API الرسمية** و **whatsapp-web.js (Puppeteer)**.
- إرسال إشعارات فورية وتلقائية للعميل عند تسجيل الفاتورة، وعند جاهزية الصور/الألبومات للاستلام، وتأكيدات الدفعات.
- نافذة محادثات واتساب مدمجة وسريعة للتواصل المباشر مع العملاء ومشاركة تفاصيل الحجوزات.
- إرسال ملخص تقرير الإيرادات اليومي تلقائياً أو عند إغلاق البرنامج إلى رقم واتساب الإدارة.

### 4. 👥 شؤون الموظفين والرواتب والعمولات (HR & Payroll)
- ملف تعريفي لكل موظف وبائع يشمل الراتب الأساسي ونوع الحساب.
- حساب العمولات التلقائية للبائعين بناءً على المبيعات والفواتير المسجلة.
- تسجيل الحضور والانصراف، السلفيات، المكافآت، والخصومات.
- إدارة فترات العمل والشفتات اليومية وتسليم النقدية بدقة.

### 5. 💰 الخزينة والمصروفات والإيرادات
- حركة خزينة فورية لكل عملية دفع، حجز، شراء مستلزمات، أو صرف رواتب.
- دعم الخزائن المتعددة (الخزينة النقدية، فودافون كاش، إنستا باي).
- تقفيل اليومية ومطابقة النقدية في الدرج مع حسابات النظام.

### 6. 📊 التقارير والإحصائيات السريعة
- تقارير مبيعات شاملة وفورية تبحث عبر كامل قاعدة البيانات بأداء فائق (Debounced Search + DOM Pagination).
- فلاتر متقدمة حسب التاريخ، حالة الحجز، العميل، والمديونيات.
- كشوف حسابات تفصيلية للعملاء، الأرباح والخسائر، وتصدير التقارير بصيغة PDF.

### 7. 🛡️ الأمان والنسخ الاحتياطي
- نظام صلاحيات للمستخدمين (مدير Admin بصلاحيات كاملة / كاشير Cashier بصلاحيات محددة).
- تفعيل البرنامج بنظام تشفير عالي الأمان مرتبط بالرقم التسلسلي للجهاز (Hardware ID - HWID).
- نسخ احتياطي تلقائي لقاعدة البيانات SQLite محلياً عند إغلاق البرنامج، مع إمكانية استعادة النسخ في أي وقت.

## 🏗 التقنيات المستخدمة

| المكون | التقنية | الوصف |
| :--- | :--- | :--- |
| **إطار العمل** | [Electron 29](https://www.electronjs.org/) | بيئة تشغيل سطح المكتب عالية الأداء (Main & Renderer) |
| **محرك التشغيل** | [Node.js](https://nodejs.org/) | معالجة خلفية النظام وإدارة العمليات والملفات |
| **قاعدة البيانات** | [better-sqlite3](https://github.com/WiseLibs/better-sqlite3) | محرك SQLite محلي متزامن فائق السرعة يدعم المعاملات المأمونة |
| **واجهة المستخدم** | HTML5 / CSS3 / Vanilla JS | واجهة عربية RTL أصيلة وسلسة بدون أطر عمل ثقيلة لضمان خفة واستقرار الأداء |
| **الباركود** | [JsBarcode](https://lindell.me/JsBarcode/) | توليد باركود محلي دون الاعتماد على خوادم خارجية |
| **التنبيهات** | [SweetAlert2](https://sweetalert2.github.io/) | نوافذ حوارية تفاعلية حديثة لتأكيد العمليات |
| **خدمة الواتساب** | WhatsApp Cloud API & Web.js | منظومة متكاملة لإرسال الإشعارات وإدارة المحادثات |
| **الحزم والتثبيت** | [electron-builder](https://www.electron.build/) | تصدير حزم التثبيت الاحترافية لأنظمة Windows |

## 📂 هيكل المشروع

```text
photography-studio-system/
├── main.js                  # نقطة الدخول (Main Process) وإدارة النوافذ وقنوات IPC

│   └── providers/           # مزودات الخدمة (Cloud API & Web.js)

│   ├── main-dashboard.html  # لوحة التحكم الرئيسية
│   ├── pos-invoice.html     # شاشة نقطة البيع وإصدار الفواتير
│   ├── reports.html         # شاشة التقارير والمبيعات السريعة
│   ├── hr.html              # إدارة الموظفين، الرواتب، والعمولات
│   ├── settings.html        # إعدادات الاستوديو، الطابعات، والباركود
│   ├── daily-report.html    # التقرير اليومي الشامل والطباعة الحرارية
│   ├── vendor/              # المكتبات المحلية (JsBarcode وغيرها)
│   ├── js/                  # ملفات المنطق البرمجي
│   └── styles/              # التنسيقات العامة والسمات
└── dist/                    # حزم البرنامج المصدرة (EXE)
```

## 🚀 التثبيت والتشغيل في بيئة التطوير

### المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو 20 يوصى به).
- أدوات البناء لـ Windows (`windows-build-tools` أو Visual Studio C++ Build Tools لتجميع `better-sqlite3`).

### خطوات التشغيل
1. **تثبيت التبعيات:**
   ```bash
   npm install
   ```

2. **تجهيز وإعادة بناء الإضافات الأصلية لـ Electron:**
   ```bash
   npm run postinstall
   ```

3. **تشغيل البرنامج في وضع التطوير:**
   ```bash
   npm start
   ```

## 📦 بناء النسخة التنفيذية (EXE)

لإنشاء ملف التثبيت النهائي `Setup.exe` والنسخة المحمولة `Portable`:

```bash
npm run build
```

ستجد الملفات المجمعة جاهزة داخل مجلد `dist/`:
- **ملف التثبيت:** `dist/Photography Studio System Setup 1.0.0.exe`
- **النسخة المباشرة بدون تثبيت:** `dist/win-unpacked/Photography Studio System.exe`

## 🔒 الأمان والصلاحيات

- **حساب المدير (Admin):**
  - وصول كامل وشامل لكافة التقارير، الخزينة، الأرباح، الرواتب، حذف الفواتير، وإعدادات النظام والطابعات.
- **حساب الكاشير (Cashier):**
  - مقيد بعمليات البيع وإصدار الفواتير وتسليم الطلبات فقط.
  - إمكانية حجب التقارير، شؤون الموظفين، الحسابات المالية، والخصومات حسب إعدادات الإدارة.
