## 🌟 المميزات الرئيسية

### 1. 🧾 نقطة البيع وإصدار الفواتير (POS)
- واجهة كاشير سريعة وسلسة تدعم اختصارات لوحة المفاتيح والشاشات التي تعمل باللمس.
- إدارة خدمات التفصيل والتصليح، مع إمكانية تعديل الأسعار، الخصومات (مبلغ أو نسبة)، والمقدم/المدفوع، وحساب المتبقي تلقائياً.
- ربط الفاتورة بالعميل، والخياط المسؤول، وموظف الكاشير.
- طباعة إيصالات حرارية قياسية (Thermal Receipts 68mm/80mm) عالية الوضوح تشمل شعار المحل، تفاصيل العميل، اسم الخياط، اسم الكاشير، QR Code، والملاحظات الخاصة.
- متابعة دورة حياة الفاتورة: (`تحت الشغل` 🛠️ ⬅️ `في انتظار الاستلام` 📦 ⬅️ `تم التسليم` ✅ ⬅️ `مرتجع` ❌).

### 2. ✂️ التعديل الذكي لخياط الفاتورة ونقل الحسابات الفوري
- إمكانية تعديل اسم الخياط المسندة إليه أي فاتورة مباشرة من صفحة التقارير.
- **حماية أمنية برمز PIN**: لا يمكن تغيير الخياط إلا بعد إدخال رمز أمان مكوّن من 6 أرقام (يمكن للمدير تخصيصه وتعديله من الإعدادات).
- **انعكاس مالي ومرتبات فوري 100%**: بمجرد تعديل الخياط، تُنقل قيمة الفاتورة وحساب عمولتها ومرتجعاتها تلقائياً من مرتب الخياط السابق إلى حساب ومرتب الخياط الجديد في جميع كشوفات المرتبات والتقارير.

### 3. 💬 تكامل الواتساب الذكي (WhatsApp Cloud API)
- شات محادثات واتساب مدمج وسريع داخل البرنامج للتواصل المباشر مع العملاء.
- مزامنة آلية بدون تدخل يدوي مع خوادم Meta Webhook عبر نفق آمن ومستقر.
- إرسال إشعارات تلقائية للعميل عند تغير حالة الطلب ("جاهز للاستلام" / "تم التسليم").
- إمكانية استعراض فواتير العميل داخل الشات بضغطة زر ونسخ ملخص الفاتورة لإرساله مباشرة.
- إمكانية حذف المحادثات والرسائل وسرعة استجابة فائقة.

### 4. 👥 شؤون الموظفين والرواتب والعمولات (HR & Payroll)
- ملف تعريفي لكل موظف وخياط يشمل الراتب الأساسي ونوع الحساب (راتب ثابت، نسبة عمولة، أو كلاهما).
- حساب العمولات التلقائية بناءً على مبيعات ومرتجعات كل خياط.
- تسجيل الحضور والانصراف، السلفيات، الخصومات، والمكافآت.
- إدارة العهد المالية وتسليم شفتات الكاشير بدقة.

### 5. 💰 الخزينة والمصروفات والإيرادات
- حركة خزينة فورية لكل عملية بيع، شراء، سداد، أو صرف مرتبات.
- تصنيف المصروفات التشغيلية والنثرية وإيرادات المحل.
- تقفيل اليومية ومطابقة النقدية في الدرج مع النظام.

### 6. 📊 التقارير والإحصائيات وإرسال اليومية
- تقارير مبيعات مفصلة مع فلاتر حسب التاريخ، الخياط، حالة الفاتورة، والمديونيات.
- إرسال ملخص تقرير المبيعات اليومي تلقائياً أو عند إغلاق البرنامج عبر الواتساب للمالك.
- تقارير أرباح وخسائر دقيقة وإحصائيات أداء الخياطين.

### 7. 🛡️ الأمان والنسخ الاحتياطي
- نظام صلاحيات للمستخدمين (مدير Admin بصلاحيات مطلقة / كاشير Cashier بصلاحيات مقيدة لحماية البيانات).
- تفعيل البرنامج بنظام تشفير مرتبط بالرقم التسلسلي للجهاز (Hardware ID - HWID).
- نظام نسخ احتياطي تلقائي لقاعدة البيانات محلياً عند كل إغلاق، مع سهولة استرجاع النسخ في أي وقت.

## 🏗 التقنيات المستخدمة

| المكون | التقنية | الوصف |
| :--- | :--- | :--- |
| **إطار العمل** | [Electron 29](https://www.electronjs.org/) | بيئة تشغيل سطح المكتب متعددة العمليات (Main & Renderer) |
| **محرك التشغيل** | [Node.js](https://nodejs.org/) | معالجة خلفية النظام وإدارة العمليات والملفات |
| **قاعدة البيانات** | [better-sqlite3](https://github.com/WiseLibs/better-sqlite3) | محرك SQLite محلي فائق السرعة متزامن ويدعم المعاملات (Transactions) |
| **واجهة المستخدم** | HTML5 / CSS3 / Vanilla JS | واجهة عربية RTL أصيلة بدون أطر عمل ثقيلة لضمان خفة الأداء |
| **التنبيهات والمودال**| [SweetAlert2](https://sweetalert2.github.io/) | نوافذ تفاعلية حديثة لإدخال وتأكيد العمليات |
| **التكامل الخارجي** | Meta Graph API & Webhooks | ربط واتساب السحابي المباشر لإرسال واستقبال الرسائل |
| **الحزم والتثبيت** | [electron-builder](https://www.electron.build/) | إنشاء ملفات التثبيت الصامتة والـ Portable لنظام Windows |

## 📂 هيكل المشروع

```text
EL_Tarzy/
├── main.js                  # نقطة الدخول (Main Process) وإدارة النوافذ وقنوات IPC
├── preload.js               # جسر الأمان الوسيط المعزول بين واجهة المستخدم وخلفية النظام
├── package.json             # تعريف المشروع والتبعيات وأوامر البناء
├── constants.js             # الثوابت العامة وإعدادات النظام
├── activation.js            # نظام التحقق والتفعيل المشفر برقم الهاردوير
├── database/
│   ├── db.js                # معالج استعلامات قاعدة البيانات، الهجرات (Migrations)، والـ IPC Handlers
│   ├── schema.sql           # مخطط الجداول وقواعد البيانات
│   └── seed.js              # البيانات الأولية والإعدادات الافتراضية
├── whatsapp/
│   ├── whatsapp-cloud-service.js # مزامنة Meta Cloud API، الاستقبال، والإرسال
│   └── tunnel-manager.js    # إدارة النفق الآمن واستخراج الرابط للمزامنة
├── renderer/
│   ├── index.html           # شاشة نقطة البيع وإصدار الفواتير الرئيسية
│   ├── reports.html         # شاشة التقارير والمبيعات وتعديل الخياطين
│   ├── hr.html              # إدارة الموظفين، الرواتب، الشفتات، والعهد
│   ├── whatsapp.html        # شاشة شات محادثات الواتساب المدمجة
│   ├── settings.html        # إعدادات النظام، الصلاحيات، ورمز الـ PIN
│   ├── customers.html       # إدارة العملاء وكشوف الحسابات
│   ├── suppliers.html       # إدارة الموردين وفواتير الشراء
│   ├── treasury.html        # إدارة الخزينة والمصروفات والإيرادات
│   ├── js/                  # ملفات المنطق البرمجي المفصولة لكل صفحة
│   └── css/                 # ملفات التنسيقات العامة والسمات
└── dist/                    # حزم البرنامج المصدرة والنسخ التنفيذية (EXE)
```

## 🚀 التثبيت والتشغيل في بيئة التطوير

### المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو 20 يوصى به).
- أدوات البناء لـ Windows (`windows-build-tools` أو Visual Studio C++ Build Tools لتجميع `better-sqlite3`).

### خطوات التشغيل
1. **تثبيت التبعيات:**
   ```bash
   npm install
   ```

2. **تجهيز وإعادة بناء الإضافات الأصلية لـ Electron:**
   ```bash
   npm run postinstall
   ```

3. **تشغيل البرنامج في وضع التطوير:**
   ```bash
   npm start
   ```

## 📦 بناء النسخة التنفيذية (EXE)

لإنشاء ملف التثبيت النهائي `Setup.exe` والنسخة المحمولة `Portable`:

```bash
npm run build
```

ستجد الملفات المجمعة جاهزة داخل مجلد `dist/`:
- **ملف التثبيت:** `dist/El-Tarzy Setup 2.2.4.exe`
- **النسخة المباشرة بدون تثبيت:** `dist/win-unpacked/El-Tarzy.exe`

## 🔒 الأمان والصلاحيات

- **حساب المدير (Admin):**
  - وصول كامل وشامل لكافة التقارير، الخزينة، الأرباح، الرواتب، حذف الفواتير، وإعدادات النظام.
  - إمكانية تغيير رمز أمان PIN الخاص بتعديل الخياطين.
- **حساب الكاشير (Cashier):**
  - مقيد بعمليات البيع وإصدار الفواتير وتغيير حالات الطلبات وتسليمها فقط.
  - محجوب عنه تماماً الوصول للإحصائيات المالية، كشوفات رواتب الموظفين، وأزرار حذف السجلات.
